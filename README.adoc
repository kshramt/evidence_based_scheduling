= Evidence Based Scheduling

image:https://github.com/kshramt/evidence_based_scheduling/actions/workflows/ci.yml/badge.svg["ci", link="https://github.com/kshramt/evidence_based_scheduling/actions/workflows/ci.yml"]

This is a TODO application, which offers the following features:

1. https://www.joelonsoftware.com/2007/10/26/evidence-based-scheduling/[The evidence based scheduling method]
2. https://jameshfisher.com/2013/12/19/todo-dag/[DAG-based dependency management]
3. https://web.dev/learn/pwa/[Offline-first PWA]

== Usage

=== Deploy on the Linux amd64 server

Keep the existing checkout on the server so Compose continues to use the same project and PostgreSQL data directory. Check that `docker --context rootless info` connects to the daemon you currently use. If the context does not exist, create it once.

[source,bash]
----
docker context create rootless --docker "host=unix:///run/user/$(id -u)/docker.sock"
----

Create `~/.config/evidence-based-scheduling/deploy.env` on the server with mode `0600`. Use the current database passwords. If you already set `MY_HOST_PGDATA` or custom ports, carry those settings over.

[source,bash]
----
install -d -m 700 ~/.config/evidence-based-scheduling
(umask 077 && touch ~/.config/evidence-based-scheduling/deploy.env)
chmod 600 ~/.config/evidence-based-scheduling/deploy.env
${EDITOR:-vi} ~/.config/evidence-based-scheduling/deploy.env
----

[source,dotenv]
----
_POSTGRES_PASSWORD='existing-postgres-password'
_POSTGRES_APP_USER_PASSWORD='existing-app-password'
----

To check that Compose can read the settings without printing the resolved configuration, run this from the checkout.

[source,bash]
----
docker compose --env-file ~/.config/evidence-based-scheduling/deploy.env -f compose.yaml -f compose.prod.yaml config -q
----

After the main CI run has published the images, SSH in, enter the existing checkout on `main`, and run the following command.

[source,bash]
----
git pull --ff-only origin main && scripts/deploy.sh
curl -fsS http://127.0.0.1:8080/api/v2/sys/health
----

Use the configured Envoy HTTP port in the health check. The deploy script uses the checked-out commit's `h-<sha>-linux-amd64` tag for all images. Compose pulls the images before recreating any containers. If a pull fails, retry once the images are available.

=== Start with an explicit image tag

[source,bash]
----
TAG=latest-linux-amd64 _POSTGRES_PASSWORD=postgres_password _POSTGRES_APP_USER_PASSWORD=postgres_app_user_password scripts/launch.sh
----

== Development

=== Local tools

Install https://mise.jdx.dev/installing-mise.html[mise] (on macOS with Homebrew, `brew install mise`). Run these commands from the repository root.

[source,bash]
----
mise install
mise exec -- pnpm install --frozen-lockfile
mise exec -- pnpm --dir client exec playwright install chromium
----

Run the client checks, which launch Chromium.

[source,bash]
----
mise exec -- make check
----

After updating Playwright, rerun the Chromium installation command before running the client checks.

When updating a tool version, update `mise.toml` and the corresponding Dockerfile pin together. Run the pin check with the project's Python version.

[source,bash]
----
mise exec -- uv run --no-project --python 3.12.4 python -B tests/test_toolchain.py
----

=== Run the app locally

Start the app and its services with Docker Compose.

[source,bash]
----
MY_HOST_PGDATA=./pgdata1 _POSTGRES_PASSWORD=postgres_password _POSTGRES_APP_USER_PASSWORD=postgres_app_user_password docker compose -f compose.yaml -f compose.dev.yaml up --build
----

Open `http://localhost:8080/app/`. To work on the client with Vite, keep Compose running and start Vite in a second terminal.

[source,bash]
----
mise exec -- pnpm --dir client dev --port 3122
----

Open `http://localhost:3122`.

=== DevContainer

Please share `/` to run the devcontainer on macOS ( https://docs.docker.com/desktop/settings/mac/#file-sharing ).

Please run the following commands for the first run.

[source,bash]
----
$ sudo chown <you>:<you> ~/.cache
$ sudo chown <you>:<you> ~/.cargo
----

=== OpenAPI Zod Client

[source,bash]

mise exec -- pnpm --dir client exec openapi-zod-client ../openapi/api_v2.yaml -o src/gen/api/v2.ts
----
