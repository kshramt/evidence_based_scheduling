## 2026-03-15 - Material Icon Ligature Accessibility Trap
**Learning:** In this application, many `btn-icon` components (like `StartButton`, `AddButton`) rely on Material Icons rendered via text ligatures inside `<span>` tags within `consts.tsx`. Because these `<span>` elements lack `aria-hidden="true"`, screen readers will announce the literal text of the ligature (e.g., "play arrow" or "add") instead of the button's actual function. Furthermore, many icon-only buttons entirely lack `aria-label`s or `title` attributes, making their purpose ambiguous for assistive tech users and sighted users needing tooltips.
**Action:** Always ensure that icon-only buttons define an explicit `aria-label` and `title` to override any ligature text and provide proper accessibility and tooltip support.
