## 2024-06-03 - Accessible Icon Buttons in Entry Components
**Learning:** Found an accessibility pattern where numerous icon-only buttons across the client app lacked `aria-label` and `title` attributes. This impacted the primary action buttons for node operations like starting, stopping, pinning, evaluating, and moving entries, making them practically invisible to screen readers.
**Action:** Always add explicit `aria-label` (for screen readers) and `title` (for tooltips on hover) to all icon-only action buttons. Added a comprehensive set to `StartButton`, `StartConcurrentButton`, `TodoToDoneButton`, `TodoToDontButton`, `DoneOrDontToTodoButton`, `EvalButton`, `TopButton`, `AddButton`, `CopyNodeIdButton`, `StopButton`, `ShowDetailsButton`, `TogglePinButton`, `ToggleButton`, `QueueEntry`, and buttons defined in `EntryButtons` and `components.tsx`.
