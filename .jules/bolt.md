## 2024-06-12 - List item components should use React.memo
**Learning:** List item components in this codebase (like `QueueEntry`, `MobileQueueNode`, `TreeEntry`, `EdgeRow`) receive primitive props (like `node_id` or `index`) but are rendered inside virtualized lists (`react-virtuoso`) or large mapped arrays. Because they rely on their own Redux-like selectors to fetch complex state internally, they are excellent candidates for `React.memo()`. This prevents O(N) re-renders when the parent list structure updates but the individual item's props haven't changed.
**Action:** When creating new list-item components or refactoring existing ones that accept primitive props, explicitly wrap them in `React.memo()` and set `.displayName` to ensure they don't unnecessarily re-render and maintain React DevTools readability.
