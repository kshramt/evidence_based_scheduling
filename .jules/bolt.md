## 2026-06-16 - React.memo on Virtuoso List Items\n**Learning:** List item components passed to Virtuoso or rendered via map that receive stable primitive props (like node_id, edge_id) must be wrapped in React.memo. Otherwise, any parent state change or scroll event forces O(N) unneeded re-renders.\n**Action:** Always wrap components like QueueEntry, MobileQueueNode, TreeEntry, and EdgeRow in React.memo and assign a displayName for React DevTools.
